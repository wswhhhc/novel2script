# Novel2Script 演示步骤

## 演示前准备

1. 确认 Python 3.10+、Node.js 18+ 和 npm 可用。
2. 启动项目：

```powershell
scripts/start-dev.ps1
```

3. 打开：

```text
http://127.0.0.1:5173
```

4. 准备示例文件：

```text
examples/novel-sample-1.txt
```

## 点击步骤与预期现象

| 步骤 | 操作 | 预期现象 |
| --- | --- | --- |
| 1 | 填写标题和类型 | 表单正常输入 |
| 2 | 上传或粘贴示例小说 | 显示字数和可识别状态 |
| 3 | 点击“识别章节” | 识别出 3 个章节 |
| 4 | 点击“生成剧本” | Mock 模式生成 YAML |
| 5 | 查看 YAML | 可看到角色、场景、beats |
| 6 | 点击“重新校验” | 显示校验通过 |
| 7 | 修改 YAML 文本 | 编辑器保留用户修改 |
| 8 | 点击“保存” | 创建本地项目 |
| 9 | 保存版本快照 | 版本历史出现新版本 |
| 10 | 恢复版本 | YAML 回到对应快照 |
| 11 | 导出 YAML / JSON / Markdown | 浏览器下载对应文件 |

## 备用话术

- 当前使用 Mock 模式，因此生成内容稳定，不依赖网络和真实 API Key。
- AI 模式已经预留并接入，需要设置环境变量后启用。
- AI 模式会发送小说内容给模型供应商，所以演示环境默认不强制启用。
- 重点不是宣称 AI 一次生成最终稿，而是提供结构化初稿、Schema 校验、可编辑和可导出链路。
- 如果现场网络或 Key 不可用，Mock 模式仍能完整展示产品闭环。

## 演示失败处理

- 后端不可用：打开 `http://127.0.0.1:8000/health` 排查。
- 前端请求失败：确认 `VITE_API_BASE_URL=http://127.0.0.1:8000`。
- 端口占用：释放 8000 / 5173 后重启。
- 导出失败：先保存项目并确认 YAML 校验通过。
- 页面异常：刷新页面，重新载入示例文本。
