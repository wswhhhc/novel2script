# Novel2Script 演示视频脚本

---

## 🎬 开场（30秒）

大家好，我是 Novel2Script 的开发者 wswhhhc。

Novel2Script 是一个 AI 驱动的小说剧本转换系统，专为小说作者、编剧初学者和短剧创作者设计。

它可以将小说文本智能转换为符合行业标准的结构化剧本初稿，大幅降低创作门槛。

接下来，让我为大家演示核心功能。

---

## 📖 功能演示 1：智能章节识别（30秒）

首先，我们打开前端工作台。

点击上传文件，选择一个测试小说。这是一个 4 章的都市爱情故事。

点击"识别章节"，系统会自动识别章节标题和内容。

可以看到，它准确识别了 4 个章节，并统计了每章的字数。

系统支持多种中英文章节格式，包括"第一章"、"Chapter 1"等多种写法。

---

## 🤖 功能演示 2：AI 五阶段剧本生成（1分钟）

接下来是核心功能：AI 剧本生成。

我们填写小说标题"重逢之后"，选择类型为"都市爱情"。

点击"生成剧本"按钮。

Novel2Script 采用创新的五阶段生成流程：

第一阶段：章节分析，提取摘要、人物、事件。
第二阶段：角色提取，解决跨章节人物去重问题。
第三阶段：场景规划，确保时空连续性。
第四阶段：生成完整 YAML 剧本。
第五阶段：自动修复，如果校验失败会自动迭代修复。

几秒钟后，剧本生成完成。状态栏显示"剧本生成成功，Schema 校验通过"。

可以看到，生成的剧本包含了角色信息、场景列表、对白和动作描述，结构非常完整。

---

## 📝 功能演示 3：YAML 编辑器（30秒）

右侧是基于 Monaco Editor 的专业编辑器。

它提供语法高亮、自动补全和实时校验功能。

我们可以直接编辑 YAML 代码，修改角色对白或场景描述。

编辑后点击"校验 YAML"，系统会立即告诉你是否符合 Schema 规范。

如果有错误，会精确定位到行号，并提供中文错误说明。

---

## 💾 功能演示 4：项目与版本管理（30秒）

Novel2Script 提供类似 Git 的版本控制系统。

点击"保存项目"，输入项目名称，剧本就保存到本地数据库了。

我们还可以创建版本快照。点击"保存版本"，输入版本名称和备注。

在版本历史中，可以看到所有保存的版本。

如果对修改不满意，一键点击"恢复版本"，就能回到之前的状态。

这样可以放心大胆地修改，不用担心数据丢失。

---

## 📤 功能演示 5：多格式导出（30秒）

最后是导出功能。

Novel2Script 支持三种格式：

YAML 格式：适合版本控制和机器处理。
JSON 格式：适合 API 集成和数据交换。
Markdown 格式：人类可读，适合打印和分享。

点击任意导出按钮，文件会自动下载到本地。

---

## ✨ 技术亮点（30秒）

Novel2Script 的技术亮点包括：

一、五阶段 AI 生成链路，确保角色一致性和结构完整性。

二、332 行的严格 JSON Schema，涵盖 ID 格式、类型约束、引用完整性。

三、双模式架构，Mock 模式用于演示，AI 模式用于实际生成。

四、完整的前后端分离架构，FastAPI + React + TypeScript。

五、支持 DeepSeek、GPT、Claude 等多种 AI 模型。
