# Demo 视频制作指南

本文档提供完整的 AI 配音演示视频制作流程。

---

## 🎯 制作方案（推荐）

### 方案一：剪映（最简单）⭐⭐⭐

**适合人群**：新手、快速制作

**优点**：
- ✅ 免费、无水印
- ✅ 录屏、配音、剪辑一体化
- ✅ AI 配音质量好
- ✅ 操作简单

**制作步骤**：

#### 1. 下载剪映
- 官网：https://www.capcut.cn/
- 下载 PC 专业版

#### 2. 录制屏幕
```
方法 A：使用剪映录屏
1. 打开剪映 → 开始创作
2. 点击顶部"录屏"按钮
3. 选择录制区域（推荐全屏）
4. 开始录制，按照脚本操作演示

方法 B：使用 Windows 自带录屏（Win + G）
1. 按 Win + G 打开 Xbox Game Bar
2. 点击录制按钮
3. 录制完成后导入剪映
```

#### 3. 添加 AI 配音
```
1. 导入录制的视频到剪映时间线
2. 点击"文本" → "智能字幕"（可选，先生成字幕）
3. 或直接点击"文本" → "新建文本"
4. 复制脚本内容到文本框
5. 点击文本 → 选择"文字朗读"
6. 选择声音（推荐："温柔女声-知性" 或 "磁性男声-浑厚"）
7. 调整语速（建议 1.0x 或 1.1x）
8. 点击"应用"
```

#### 4. 音画对齐
```
1. 拖动配音音频到对应的视频片段
2. 在关键操作处（点击按钮等）适当暂停画面
3. 使用"定格"功能保持画面不动
4. 确保配音和操作同步
```

#### 5. 添加字幕（可选）
```
1. 点击"文本" → "识别字幕"
2. 自动生成字幕
3. 调整字幕样式（字体、大小、颜色）
4. 推荐使用底部居中，黑色背景 + 白色文字
```

#### 6. 导出视频
```
1. 点击右上角"导出"
2. 分辨率：1920x1080（1080p）
3. 帧率：30fps
4. 格式：MP4
5. 导出并保存
```

### 方案二：OBS Studio + Azure TTS（专业）⭐⭐

**适合人群**：追求质量、有一定技术基础

**工具组合**：
- OBS Studio（录屏）：https://obsproject.com/
- Azure TTS（配音）：https://speech.microsoft.com/
- DaVinci Resolve 或 Premiere Pro（剪辑）

**优点**：
- ✅ 专业级质量
- ✅ Azure TTS 语音最自然
- ✅ 完全免费

**制作步骤**：

#### 1. 使用 Azure TTS 生成配音

**注册 Azure**：
```
1. 访问：https://azure.microsoft.com/
2. 注册免费账号（需要信用卡验证，但不扣费）
3. 创建"语音服务"资源
4. 获取 API Key
```

**在线试听工具**：
```
1. 访问：https://speech.microsoft.com/portal/voicegallery
2. 选择声音：
   - 女声：zh-CN-XiaoxiaoNeural（云希，温柔）
   - 男声：zh-CN-YunyangNeural（云扬，沉稳）
3. 粘贴脚本分段生成音频
4. 下载 MP3 文件
```

**使用 Python 脚本批量生成**（可选）：
```python
# 需要 pip install azure-cognitiveservices-speech
import azure.cognitiveservices.speech as speechsdk

speech_key = "YOUR_API_KEY"
service_region = "eastasia"

speech_config = speechsdk.SpeechConfig(subscription=speech_key, region=service_region)
speech_config.speech_synthesis_voice_name = "zh-CN-XiaoxiaoNeural"

audio_config = speechsdk.audio.AudioOutputConfig(filename="output.wav")
synthesizer = speechsdk.SpeechSynthesizer(speech_config=speech_config, audio_config=audio_config)

# 分段配音
text = """
大家好，我是 Novel2Script 的开发者 wswhhhc。
Novel2Script 是一个 AI 驱动的小说剧本转换系统...
"""

result = synthesizer.speak_text_async(text).get()
```

#### 2. 使用 OBS Studio 录屏

**下载安装**：
```
1. 访问：https://obsproject.com/
2. 下载并安装
3. 首次打开会有自动配置向导
```

**录制设置**：
```
1. 添加来源：
   - 点击"+"
   - 选择"显示器采集"
   - 选择主显示器

2. 录制设置：
   - 设置 → 输出 → 录制格式：MP4
   - 视频比特率：6000 Kbps
   - 编码器：x264

3. 分辨率：
   - 设置 → 视频 → 基础分辨率：1920x1080
   - 输出分辨率：1920x1080

4. 开始录制：
   - 点击"开始录制"
   - 按照脚本操作演示
   - 完成后点击"停止录制"
```

#### 3. 剪辑合成

使用 DaVinci Resolve（免费）或任何视频编辑软件：
```
1. 导入录制的视频
2. 导入 Azure TTS 生成的音频
3. 音画对齐
4. 添加字幕（可选）
5. 导出 1080p MP4
```

## 📹 录屏技巧

### 录制前准备
```
1. ✅ 清理桌面，关闭无关窗口
2. ✅ 关闭通知（Win 10/11：通知中心 → 专注助手）
3. ✅ 设置浏览器缩放为 100%
4. ✅ 全屏录制（1920x1080）
5. ✅ 准备好示例数据（novel-demo-test.txt）
6. ✅ 启动前后端服务
```

### 录制建议
```
1. 鼠标移动要缓慢流畅
2. 点击按钮时稍作停顿（便于后期剪辑）
3. 每个功能演示完后停留 1-2 秒
4. 避免快速切换页面
5. 如果操作失误，可以重录该段
```

### 录制顺序
```
按照脚本顺序录制：
1. 开场（可以后期加标题动画）
2. 章节识别演示
3. AI 生成演示
4. YAML 编辑演示
5. 项目管理演示
6. 导出功能演示
7. 结尾（可以后期加感谢页面）
```

## 🎨 视频美化建议

### 开场动画（可选）
```
使用剪映模板：
1. 剪映 → 素材库 → 搜索"科技开场"
2. 选择一个模板
3. 替换文字为项目名称
4. 时长：3-5 秒
```

### 字幕样式
```
推荐设置：
- 字体：思源黑体 或 阿里巴巴普惠体
- 大小：适中（不要太大）
- 颜色：白色文字 + 半透明黑色背景
- 位置：底部居中
- 动画：淡入淡出
```

### 背景音乐（可选）
```
建议：
- 音量：很低（10-15%），不要盖过配音
- 类型：轻音乐、科技感 BGM
- 来源：剪映素材库（免费无版权）
- 推荐搜索："科技"、"轻快"、"商务"
```

### 转场效果
```
建议：
- 使用简单的淡入淡出
- 避免花哨的转场
- 功能间切换可用"闪白"转场
- 时长：0.3-0.5 秒
```
