### 3. 详化 YAML Schema 约束（优化第 9 节）

#### 3.1 新增 9.1 节：字段约束规则
为每个字段补充详细的约束说明：

**script 顶层字段**
- `title`: string, 必填，1-100 字符
- `genre`: string, 必填
- `version`: string, 必填，版本号格式
- `created_at`: string, 可选，ISO 8601 格式

**characters 字段**
- `id`: string, 必填，格式 CHAR001-CHAR999，唯一
- `name`: string, 必填，2-20 字符
- `role`: string, 必填（主角、配角、群众）
- `description`: string, 可选，最多 500 字符
- `personality`: string[], 可选
- `first_appearance`: string, 必填，引用 chapter.id
- `relationships`: object[], 可选

**scenes 字段**
- `id`: string, 必填，格式 S001-S999，唯一
- `beats`: [], 必填，至少 3 个 beats

**beats 字段**
- 详细说明 5 种类型：action、dialogue、narration、transition、note
- 明确 dialogue 类型的特殊要求

**adaptation_notes 字段**
- `type`: deletion | merge | transformation | addition
- `description`: 必填
- `reason`: 必填

### 5. 新增质量评估标准（优化 11.3 节）

#### 5.1 最低质量要求（强制）
- ✅ 角色名称一致性：100% 一致
- ✅ 场景完整性：每个场景至少 3 个 beats
- ✅ 对白合理性：占比 40%-70%
- ✅ 来源可追溯：每个场景必须追溯到源章节
- ✅ 时间线连贯：无矛盾
- ✅ 角色引用合法性：所有角色必须在角色表中存在
- ✅ ID 唯一性：所有 ID 必须唯一

#### 5.2 可选质量指标（优化方向）
- ✅ 角色出场频率相符度 > 80%
- ✅ 关键剧情保留完整度 > 90%
- ✅ 场景拆分合理性（人工评估）
- ✅ 对白符合人物性格（人工评估）
- ✅ 动作描写可拍摄性（人工评估）
