接口要求
====================

## 1. 章节解析接口

接口：

POST /api/chapters/parse

请求体：

{
  "content": "小说全文"
}

响应体：

{
  "chapter_count": 3,
  "valid": true,
  "message": "章节识别成功",
  "chapters": [
    {
      "id": "C001",
      "title": "第一章 雨夜来客",
      "content": "章节正文",
      "word_count": 3200
    }
  ]
}

实现要求：

- 支持至少以下章节标题格式：
  - 第1章
  - 第一章
  - Chapter 1
  - 1.
  - 一、
  - 卷一 第一章
- 章节 ID 从 C001 开始递增。
- word_count 使用章节正文长度计算。
- 如果章节数量小于 3，返回 valid=false，并给出明确 message。
- 如果无法识别章节，也要返回 valid=false，并给出明确 message。
- 不要在本阶段实现 AI 智能识别和手动标注，只保留清晰的 TODO 注释即可。

## 2. YAML 校验接口

接口：

POST /api/script/validate

请求体：

{
  "yaml": "script:\n  title: ..."
}

响应体：

{
  "valid": true,
  "errors": []
}

实现要求：

- 使用 PyYAML 解析 YAML。
- 使用 jsonschema 加载 `schemas/script.schema.json` 校验结构。
- 校验失败时返回 valid=false。
- errors 中应包含尽量清晰的错误信息。
- 需要处理 YAML 语法错误、JSON Schema 校验错误和文件不存在等异常。
- 除 JSON Schema 校验外，请额外实现以下业务校验：
  - chapter id 唯一
  - character id 唯一
  - scene id 唯一
  - characters[].first_appearance 必须引用存在的章节
  - scenes[].source_chapters 必须引用存在的章节
  - scenes[].characters 必须引用存在的角色
  - dialogue beat 的 character 必须引用存在的角色

## 3. 剧本生成接口

接口：

POST /api/script/generate

请求体：

{
  "title": "小说标题",
  "genre": "悬疑",
  "chapters": [
    {
      "id": "C001",
      "title": "第一章",
      "content": "章节正文",
      "word_count": 3000
    }
  ]
}

响应体：

{
  "yaml": "script:\n  title: ...",
  "validation": {
    "valid": true,
    "errors": []
  }
}

实现要求：

- 本阶段不接入真实 AI。
- 直接读取 `examples/script-output-1.yaml` 作为 mock 生成结果。
- 调用 YAML 校验服务校验 mock 结果。
- 返回 YAML 字符串和校验结果。
- 如果输入章节少于 3，应返回明确错误。
