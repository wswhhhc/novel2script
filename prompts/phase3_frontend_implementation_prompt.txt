你是一个资深前端开发工程师。请基于当前项目需求文档和已完成的第二阶段后端，实现 Novel2Script 项目的第三阶段任务：前端工作台。

====================
任务背景
====================

项目名称：Novel2Script：AI 小说转剧本创作助手

项目目标：
开发一款 AI 辅助剧本创作工具，支持用户输入 3 个章节以上的小说文本，自动生成符合 YAML Schema 的结构化剧本初稿。

当前已经完成：

- 需求文档：docs/requirements.md
- YAML Schema 文档：docs/yaml-schema.md
- JSON Schema：schemas/script.schema.json
- 标准 YAML 示例：examples/script-output-1.yaml
- 后端核心接口：backend/
- 阶段 Prompt：prompts/

你需要完成第三阶段前端工作台。

====================
第三阶段目标
====================

请搭建 React + Vite + TypeScript 前端项目，实现一个可用的小说转剧本工作台。

用户应能够完成以下流程：

1. 粘贴或上传小说文本。
2. 点击识别章节。
3. 查看章节识别结果。
4. 当章节数量满足要求时，点击生成剧本。
5. 查看后端返回的 YAML 剧本。
6. 编辑 YAML。
7. 重新校验 YAML。
8. 复制或下载 YAML 文件。

本阶段不需要接入真实 AI，不需要登录，不需要数据库，不需要复杂权限系统。

## 2. 章节解析

POST /api/chapters/parse

请求：

{
  "content": "小说全文"
}

响应：

{
  "chapter_count": 3,
  "valid": true,
  "message": "章节识别成功",
  "warnings": [],
  "chapters": [
    {
      "id": "C001",
      "title": "第一章 雨夜来客",
      "content": "章节正文",
      "word_count": 3200
    }
  ]
}

POST /api/script/validate

====================
页面目标
====================

请构建一个工具型工作台，而不是营销落地页。

页面第一屏就应该是可用的工作区，包含：

- 小说标题输入
- 剧本类型输入或选择
- 小说文本输入
- 文件上传
- 章节识别按钮
- 章节列表
- 生成剧本按钮
- YAML 编辑区
- 校验结果
- 复制和下载按钮

推荐布局：

左侧：小说输入和文件上传
中间：章节识别结果和生成状态
右侧：YAML 编辑器、校验结果、复制下载操作

页面应适配桌面和移动端：

- 桌面端可以使用三栏布局。
- 平板和移动端应改为单列或上下布局。
- 不允许文字和按钮内容溢出容器。

====================
交互状态
====================

请实现以下状态：

1. 初始状态
   - 小说文本为空
   - 识别章节按钮禁用
   - 生成剧本按钮禁用

2. 文本已输入
   - 显示字数统计
   - 识别章节按钮可用

3. 章节识别中
   - 显示加载状态
   - 禁用重复提交

4. 章节识别成功
   - 展示章节数量
   - 展示章节列表
   - 每个章节显示 id、title、word_count
   - 可折叠查看正文摘要或前若干字

5. 章节数量不足或识别失败
   - 显示后端 message
   - 生成剧本按钮禁用

6. 有 warnings
   - 显示警告信息
   - 不阻止生成

7. 剧本生成中
   - 显示加载状态
   - 显示阶段提示，例如“正在生成 YAML 剧本”

8. 生成成功
   - YAML 编辑区加载返回内容
   - 显示校验状态
   - 启用复制、下载、重新校验

9. YAML 校验失败
   - 展示错误列表
   - 不清空用户编辑内容

10. 请求失败
   - 显示错误信息
   - 保留用户输入内容

====================
组件要求
====================

## NovelInput

功能：

- 小说标题输入
- 类型输入或选择
- 小说正文 textarea
- 字数统计
- 清空按钮

要求：

- 标题默认可以为空，但生成时应提示填写标题。
- 类型默认可以是“悬疑”或“未分类”。
- 正文为空时禁用章节识别按钮。

## FileUpload

功能：

- 支持 `.txt` 和 `.md`
- 文件最大 10MB
- 读取文本后填充到小说正文输入区

要求：

- 文件类型错误时提示。
- 文件过大时提示。

## ChapterList

功能：

- 展示章节识别结果
- 展示 `chapter_count`
- 展示 `valid`
- 展示 `message`
- 展示 `warnings`
- 章节项展示 id、title、word_count

要求：

- warnings 使用警告样式，但不阻断操作。
- invalid 使用错误样式，并禁用生成按钮。

## GenerationPanel

功能：

- 识别章节按钮
- 生成剧本按钮
- 展示加载状态

要求：

- 章节未识别或 invalid 时，生成按钮禁用。
- 生成时禁用重复点击。

## YamlEditor

功能：

- 展示和编辑 YAML
- 支持复制
- 支持下载 `.yaml`
- 支持重新校验

要求：

- 优先使用 Monaco Editor。
- 如果没有 Monaco Editor，可先用 textarea，但组件命名仍为 YamlEditor。
- 用户编辑内容后，应允许重新调用 `/api/script/validate`。

## ValidationPanel

功能：

- 展示 valid 状态
- 展示 errors 列表

要求：

- valid=true 时显示通过。
- valid=false 时显示错误列表。

====================
类型定义
====================

请在 `frontend/src/api/types.ts` 定义后端接口类型，例如：

export interface Chapter {
  id: string;
  title: string;
  content: string;
  word_count: number;
}

export interface ParseChaptersResponse {
  chapter_count: number;
  valid: boolean;
  message: string;
  warnings: string[];
  chapters: Chapter[];
}

export interface ValidationResponse {
  valid: boolean;
  errors: string[];
}

export interface GenerateScriptResponse {
  yaml: string;
  validation: ValidationResponse;
}
