====================
任务背景
====================

项目名称：Novel2Script：AI 小说转剧本创作助手

项目目标：
开发一款 AI 辅助剧本创作工具，支持用户输入 3 个章节以上的小说文本，自动生成符合 YAML Schema 的结构化剧本初稿，并支持编辑、校验、保存、版本管理和导出。

当前已经完成：

- 第一阶段：需求、Schema、Prompt 模板和标准 YAML 示例
- 第二阶段：FastAPI 后端核心接口
- 第三阶段：React 前端工作台
- 第四阶段：测试优化、示例数据和验收文档
- 第五阶段：真实 AI 生成链路接入与稳定化
- 第六阶段：项目保存、历史版本与 YAML / JSON / Markdown 导出

最后阶段目标是把项目整理成可以稳定演示、可以部署、可以评审、可以提交的最终作品。

====================
部署要求
====================

请提供两种部署方式。

## 1. 本地开发启动

要求：

- 支持 Windows PowerShell。
- 如条件允许，也支持 macOS / Linux shell。
- 一条脚本或清晰命令启动后端和前端。
- 明确端口：
  - 后端：http://127.0.0.1:8000
  - 前端：http://127.0.0.1:5173

建议：

```powershell
scripts/start-dev.ps1
```

或：

```bash
scripts/start-dev.sh
```

脚本应：

- 检查 Python / Node / npm 是否可用。
- 安装或提示安装依赖。
- 启动后端。
- 启动前端。
- 输出访问地址。
- 遇到端口占用时给出清晰提示。

## 2. Docker Compose 启动

要求：

- 提供 Dockerfile.backend。
- 提供 Dockerfile.frontend。
- 提供 docker-compose.yml。
- 前端容器应能访问后端 API。
- SQLite 数据目录应使用 volume 或清晰说明持久化位置。
- Mock 模式默认可运行。
- AI 模式通过环境变量启用。

建议服务：

```yaml
services:
  backend:
    ports:
      - "8000:8000"
  frontend:
    ports:
      - "5173:80"
```

不要把真实 API Key 写入 compose 文件。
